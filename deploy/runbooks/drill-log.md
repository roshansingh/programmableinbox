# DR drill log

Every monthly, quarterly, and annual drill gets one paragraph here. **No writeup = the drill didn't happen.**

## Format

### YYYY-MM-DD — <drill type>

- **Type**: monthly / quarterly / annual
- **Operator**: <name>
- **Scenario**: brief description (e.g. "fetched latest base + 4 hours of WAL from S3 into laptop docker, verified row counts")
- **Wall-clock time**: NN min
- **Notes**: anything surprising, broken, or worth changing in the runbook
